# Changelog: 2026-08-21

## Implemented

- Opened the pre-commitment upgrade drafts to every line. Before the
  primary-path milestone a draft now draws from all ten upgrade lines instead of
  only Thornshot Power and Thornshot Tempo, so the first level-up is a real
  choice. Drafts narrow to universal and selected-path lines as before once a
  primary path is committed.
- Spread each draft's three offers across the eligible pool rather than taking
  three adjacent enum entries, so a wide opening draft represents every path
  instead of the first few lines in declaration order. The offer cursor still
  advances one line per level, so the sequence stays deterministic.
- Added a requirement note to any draft button for a line whose path is not yet
  selected, because such a line only pays off if that path is chosen later.
- Replaced the smoke assertion that path lines cannot appear before commitment
  with one covering the new opening draft: three distinct lines spanning at
  least two paths, each unselected-path line labelled with its requirement.

## Bramble damage model

- Added a maximum-health component to every thorn tick, so Bramble keeps scaling
  against late-game health pools instead of falling off as enemy health grows.
- Made the Thorn Damage line raise the flat and maximum-health parts together.
- Added contact-time damage ramping. An enemy standing in developed Bramble
  takes progressively more damage up to a capped multiplier, which punishes
  slow, tanky enemies and Grazers grinding at the frontier while leaving enemies
  that pass straight through largely untouched. Accumulated contact decays
  rather than resetting, so briefly stepping out does not shake off the ramp.
- Added capped local horde-pressure scaling: a Bramble section hits harder when
  several enemies attack the same stretch of border. Counts are recomputed on a
  cadence, and the pairwise scan only covers enemies already touching a boundary.
- Added the Siege Thorns relic, which hardens a besieged frontier against
  erosion in proportion to the attackers on it, up to a capped bonus. It is
  offered only to runs that selected Bramble.
- Confirmed and covered by test that thorn damage is never divided: every enemy
  on one boundary resolves its own full calculation.
- Measured time-to-kill on continuous full-strength contact: an early Grazer
  takes 5.6 s at no investment and 2.8 s at maximum Thorn Damage; a late-invasion
  Grazer takes 8.9 s and 5.2 s; a late Warden 8.0 s, elite 9.8 s, and the
  Burrower 14.0 s at maximum Thorn Damage.
- Verified the worst case of 130 enemies clustered on one frontier section with
  a forced recount every frame at 3.0 ms average and 5.4 ms peak, inside the
  16.67 ms budget.

## Path commitment

- Taking a path-specific upgrade now commits that path into the run's next open
  path slot. Choosing Bloom Frequency at the first level-up selects Bloom as the
  primary outright, and a later Bramble line then claims the secondary slot, so a
  run can lock both paths purely through drafting.
- Generalized draft eligibility to match: every line stays draftable while either
  path slot is open, and drafts narrow to the committed lines only once both
  paths are held. Previously they narrowed as soon as the primary was chosen,
  which meant a second path's lines could never appear before its milestone.
- A milestone no longer fires for a slot that is already filled, while any slot
  still open is offered at 00:45 or 03:00 as before. The confirmation status
  names whether the adopted path became the primary or the secondary.
- Dropped the draft-button requirement label entirely. A drafted line is now
  always either universal, on an already-selected path, or the commit case that
  needs no warning, so the note had no remaining caller. The confirmation status
  after choosing still names the path that was adopted.

## Rerolls

- Added three upgrade-draft rerolls per run. A reroll redraws the current offer
  from a different point in the pool without spending a level, and the count is
  restored on restart.
- Added a reroll button to the draft panel that shows the remaining count,
  disables itself when they are spent, and is hidden for relic and path offers,
  which already present every remaining option and could not change on a redraw.

## Bramble under pressure

- Capped how much development a single erosion or conversion stamp can remove, so
  thorns degrade through visible bands instead of snapping to zero.
- Added Bramble memory. Owned ground behind the frontier keeps a fading record of
  the thorns beside it, and a border pushed backward inherits a share of that
  development instead of restarting bare.
- Gave newly exposed Mature Green a starting floor of development, so settled
  territory is never fully bare the moment it becomes frontier.
- Made a section under active attack grow back faster, letting defensive growth
  answer pressure without becoming instant.
- Gave development its own erosion resistance independent of the Bramble
  Resistance upgrade, so Grazers chew Fresh ground quickly and slow markedly
  against established thorns.
- Added an element-agnostic grazing burst and recovery window to enemy profiles,
  and gave the Grazer a pause after each burst so the frontier gets regrowth
  windows.
- Measured territory under pinned Grazer pressure: light and moderate pressure
  still lets Green grow, heavy pressure slows it, and mean frontier development
  never collapses to zero. Clearing the attackers recovers both area and thorn
  strength.

## Wave composition

- Replaced the blunt Grazer mix rule, which made every regular pack a Grazer for
  the whole second half of the run, with a pack cycle that gives Grazers roughly
  a quarter of normal packs.
- Added announced Grazer surge waves every fourth wave, which name themselves in
  the run HUD so heavy territorial pressure reads as a deliberate test.

## Performance

- Hoisted the fixed step's tuning reads out of the per-cell loop. Resource
  property lookups inside the inner loop cost more than the new Bramble work
  itself: the territory step went from 9.2 ms to 7.0 ms and the dense Sporekeeper
  fixture peak from 17.4 ms to 14.0 ms, below the pre-change 15.6 ms baseline.

## Evolution timing

- Moved the pair evolution out of the boss reward and into the level-up draft.
  A pairing becomes claimable the moment one line from each selected path hits
  level five, rather than waiting for a boss encounter that may be minutes away.
- The evolution holds one of the draft's three slots until it is taken, survives
  a reroll, and stops appearing once claimed, so a completed pairing can neither
  be missed nor rerolled away.
- Defeating the boss now offers a relic, matching the elite reward, instead of
  gating the evolution behind it.
- Updated the HUD readiness line and the F8 debug message, which both told the
  player to defeat the boss.

## Dormant and harvested Bramble

- Gave Bramble three explicit states. Active thorns sit on the frontier and deal
  damage, Dormant thorns are buried under friendly territory and deal nothing
  while storing their development, and Harvested thorns are consumed by a
  mechanic that made them obsolete.
- Renamed the former Bramble memory buffer to the dormant store and extended its
  life from 8 to 45 seconds, so thorns covered by a Seed or by natural growth
  survive being buried instead of fading within a few seconds.
- Added accelerated regrowth from the dormant store: a re-exposed cell restores
  part of its development immediately and then thickens at a multiplied rate
  while unspent dormant development remains.
- Ground lost to the enemy now clears its dormant store, since buried thorns only
  survive under friendly territory.
- Kept the store strictly local. It lives on the cell that grew it and is only
  ever seeded from an immediate neighbour, so vanishing Bramble is never
  redistributed to unrelated parts of the map.
- Added `harvest_bramble_in_radius` as the single field entry point for consuming
  thorns. It clears the inner part of a radius, spares the rim where the new
  frontier will stand, and reports total development, cell count, and
  maturity-weighted mean without deciding what the caller does with them.
- Gave the Bloom plus Bramble evolution its harvest loop: a Bloom consumes the
  frontier it is about to bury and scatters Briar Traps through the ground it
  claims, using a deterministic spiral. Harvested development sets how many Traps
  appear and harvested maturity sets how sharp they are. Traps reuse the pooled
  thorn-zone primitive that Briar Pods already use, which is safe because the two
  evolutions are mutually exclusive.
- Left Thornburst in place. The Bloom harvest replaces thorns going dormant, not
  the retaliation, so the evolution now both retaliates and harvests.

## Seed and Bloom identities

- Split the Bloom off the shared growth stamp into its own displacement rule.
  Bloom mass and pressure are now scaled by the Plant support the field finds
  between each cell and the burst origin, so a Bloom surges an existing frontier
  outward and lands nothing on ground detached from Plant. Seeds keep the
  original stamp and remain the only mechanic that colonises detached territory.
- Added a support reach so one burst can drive the frontier several cells rather
  than a single band, keeping the Bloom a strong outward push instead of a
  one-cell nudge.
- Rooted automatic Blooms on the player's own frontier cell facing the nearest
  threat, through a new `find_player_frontier_near` field query. They previously
  detonated at the threat itself, which let a Bloom claim ground far from any
  Plant and made it behave like a Seed.
- Shortened the Bloom telegraph from 1.15 s to 0.65 s and raised Bloom pressure
  to the field maximum, matching a short charge followed by a strong burst, while
  the Seed keeps its longer 1.35 s destructible germination.
- Confirmed the upgrade focuses were already separate and left them alone: Seed
  Production and Growth Mass feed only Seed germination and Seed mass, while
  Bloom Force and Bloom Frequency feed only Bloom force and cadence.
- Raised the Bloom's base spreading strength so one burst outweighs one
  germination, since Blooms fire on a 13 second cadence while Seeds arrive every
  few kills. Measured from the same frontier point over 30 steps, a Seed claimed
  1.61 percentage points of arena above natural spread while a Bloom claimed only
  1.29. Base mass moved from 0.90 to 1.90 and support reach from 3.5 to 6.5
  cells, taking the Bloom to 2.02, about 25% ahead of a Seed.
- Left the Bloom radius at 13.5 cells. It contributed almost nothing to spread in
  measurement and also drives Bloom damage, the Briar Trap harvest area, and trap
  scatter, so widening it would have changed unrelated systems.
- Reach stays under half the Bloom radius, so a Bloom still cannot claim ground
  detached from Plant, and a smoke check now pins the Bloom at or above one Seed
  from the same frontier.
- Fixed `local_to_cell`, which was missing the half cell that `cell_to_local`
  adds. The inverse landed on the neighbouring cell about half the time, so every
  position query sampled up to one cell off target. In play this rooted automatic
  Blooms one cell into hostile ground: the frontier query returned a cell reading
  -0.71 control instead of the +0.34 Plant cell it had found.
- Raised the Bloom's hostile conversion from 0.72 to 1.80 and renamed it
  `bloom_hostile_conversion_factor` to match `seed_hostile_conversion_factor`.
  Blooms root on the frontier facing the nearest threat, which is contested
  ground, and a factor below 1.0 was a penalty exactly where the path is supposed
  to excel. A Bloom on a contested border went from 0.75 to 2.34 percentage
  points against a Seed's 0.80 in the same place, so breaking through a hostile
  border is now the Bloom's job rather than its weakness.

## Root path

- Added Root as the fourth Plant path, following the GDD's identity of maturity,
  age, and compounding economy, with its four authored lines: Maturation Speed,
  Biomass Yield, Mature Resistance, and Regeneration.
- Added the two field rules Root needs. `regeneration_per_second` heals damaged
  ground the player still holds during the fixed step, and a mature-resistance
  multiplier hardens cells past the Mature threshold against erosion and hostile
  conversion. Both are field-owned rules; progression owns how much of each a run
  has earned.
- Biomass Yield multiplies only the Mature term of the economy and only while the
  Root path is held.
- Added Root's three pairings with the implemented paths, named from the GDD.
  Spore plus Root gives Seed Bank, where Mature borders bank Seeds that inherit
  their maturity as extra growth mass without needing a kill. Bloom plus Root
  gives Flowering Season, where Mature area charges a meter that spends itself on
  several Blooms at once and consumes maturity at each site. Bramble plus Root
  gives Old Growth, where Mature borders arm to full thorn development at once
  and every thorn tick cuts harder.
- Widened the primary path milestone from a hardcoded Spore/Bloom/Bramble list to
  every implemented path, and added a fourth choice button with a taller choice
  panel so a four-path offer is reachable.

## Old Growth rework

- Reworked the Bramble plus Root evolution from a defensive frontier buff into an
  offensive interior. Mature Green now deals continuous thorn damage to anything
  standing on it, so a Root build's own settled ground becomes a kill zone.
- Added an authoritative Age layer to the field, counting seconds a cell has held
  the same owner while past the Mature threshold and resetting when either lapses.
  Interior thorn damage scales from half a normal tick on freshly Mature ground to
  three quarters on ground aged to the field's reference.
- Kept the frontier hedge untouched at full strength and separated the two layers
  in combat. Only the hedge can breach or trigger Retaliation, and it is always
  the stronger of the two; the interior share is capped below it by construction.
- Entanglement slow scales with the same interior share, so old ground applies a
  reduced version of the frontier's slow without any separate rule.
- Fresh and Established ground bite for nothing, and a run without the evolution
  takes no interior damage at all.
- Removed the previous Old Growth effects, which armed Mature borders instantly
  and multiplied every thorn tick. Both buffed the frontier, which the rework
  deliberately leaves alone.
- Added a pooled root-eruption visual that bursts under each bitten enemy rather
  than carpeting the interior in spikes, plus HUD detail lines for all three Root
  evolutions.

## Bramble rework: hazardous territory

This supersedes the Bramble entries above, which built the path on the frontier.
Depending on frontier geometry made Bramble unreliable in exactly the situations
it was supposed to answer: Grazers eating territory could create new walls,
constant Seeds fragmented the border, Blooms kept moving it, interior holes made
isolated rings, and large territories made effectiveness a question of perimeter
shape. Keeping established thorns alive under heavy Grazer pressure needed a
growing pile of special-case frontier logic.

- All owned Green is now hazardous. `TerritoryField.get_bramble_coverage_at_local`
  reports whether a cell is claimed Plant ground, and every enemy standing on it
  takes thorn damage. Holes, moving borders, rings around interior gaps, and
  buried thorns no longer change whether Bramble works.
- Added Entanglement. An enemy on Green accumulates a 0-to-1 value that scales
  both its thorn damage, up to an authored multiple of the base tick, and its
  movement slow. It decays off Green rather than resetting, so a brief step out
  does not shake it loose. Fast enemies cross almost untouched; Grazers and tanky
  enemies that settle in are eventually overwhelmed.
- Lowered the base tick hard, since Bramble can now cover most of the arena:
  flat damage 2.0 to 0.6 and the max-health component 0.006 to 0.0018, with the
  fully Entangled multiplier carrying the payoff instead.
- Kept the frontier hedge as a bonus layer. Standing in developed thorns adds
  damage and builds Entanglement faster, and crossing an established hedge deals
  a one-off hit on its own per-enemy cooldown.
- Moved Retaliation onto territory damage. An enemy that erodes or converts Green
  triggers a thorn hit on a per-enemy cooldown, which is what aims it at Grazers,
  rather than triggering on first contact with the border.
- Removed the Dormant Bramble store, its dormancy, inheritance, and regrowth
  tuning, and the local frontier-memory rules that went with it. Burying thorns
  now costs only the hedge bonus, so there is nothing left to remember or
  relocate. The field step lost a buffer and a branch with it.
- Replaced the contact-time ramp, whose accumulated-seconds model Entanglement
  now covers directly.
- Reworked the upgrade lines to Thorn Damage, Ensnare Rate, Entanglement, and
  Thorn Retaliation. Bramble Resistance is gone as a line because it overlapped
  Root; selecting Bramble still supplies its frontier resistance outright, and
  the Siege Thorns relic is unaffected.
- The shader now draws a sparse thorn texture across all owned Green under the
  frontier hedge, so the hazard is visible where it actually applies.
- Scoped Siege Thorns to enemies standing in the hedge. Its attacker count used
  to be every enemy touching Bramble, which under the new coverage rule would
  have meant every enemy anywhere on the territory.
- Measured time-to-kill for a Grazer standing continuously on Green. Early, with
  Bramble selected and nothing invested: 7.5 s, rising to 12.2 s against
  final-invasion health. Maxed Thorn Damage: 4.2 s and 6.5 s. Adding maxed
  Ensnare Rate: 3.3 s and 5.6 s. A full Bramble/Root build standing on ancient
  Mature ground: 2.3 s against final-invasion health.

## Thornburst rework: Briar Trap minefields

- Dropped the retaliatory Bloom, which fired on breach events the reworked
  Bramble no longer produces, and with it the `bramble_breached` signal.
- A Bloom now harvests the Bramble covering the ground it is claiming — the
  area of Green it covers plus any hedge development standing there — and sows
  that yield as Briar Traps through the newly claimed territory. Harvest yield
  therefore scales with area rather than with a frontier being present.
- Briar Traps are a new pooled combat entity: they arm in place, detonate when an
  enemy comes close, deal area thorn damage, apply Entanglement, and emit a typed
  event the Plant director turns into a small outward territory push.
- Each detonation lights the traps within a chain radius after a short fuse, so a
  wave walking into a fresh trap field sets off a visible cascade rather than a
  single blast. Chain depth is capped.
- Traps rot on a timer, so a long run never fills the arena with mines.
- Thorn Damage raises trap damage, Entanglement deepens the Entanglement they
  apply, and Bloom Force, Mass, and Frequency decide how strong, how wide, and
  how often a field is sown.

## Root rework: the Root Network

- Root is now the scaling and amplification path rather than a bundle of passive
  territory bonuses. Mature ground publishes a Root Network amplification that
  other Plant mechanics scale by the maturity of the ground they act from.
- Seeds germinating from Mature Green carry more growth mass, Blooms opening on
  it push harder, and thorns growing in it both bite harder and ensnare faster.
- Replaced the Regeneration line with Root Potency, which raises that
  amplification. Regeneration now rides along with Mature Strength, which also
  keeps the Mature resistance it always had, because a whole draft line for
  self-healing ground overlapped Mature resistance too heavily.
- Renamed Mature Resistance to Mature Strength to match what it now does.

## Old Growth rework: root eruptions

This supersedes the Old Growth rework above. That version gave Mature interior
its own continuous thorn damage, which the reworked Bramble now supplies
everywhere, so the evolution needed a payoff beyond it.

- An enemy that becomes heavily Entangled while standing on Mature ground is
  seized by the Root Network: roots and thorn spikes erupt and strike everything
  in a radius, applying Entanglement to whatever survives.
- Eruption damage sharpens with that ground's Age, using the existing
  authoritative Age layer.
- A kill made by an eruption chains another eruption beneath the next enemy after
  a short delay, capped by chain depth, so a mob wading into ancient territory
  cascades across the network.
- Removed the interior-share tuning the previous version used; interior damage is
  now plain Bramble.

## Open work carried forward

- Entanglement pacing is set from a standing-still measurement, which is the
  worst case for the enemy. Playtesting should confirm that an enemy actually
  crossing Green at speed feels as untouched as intended; raise
  `bramble_entanglement_decay_per_second` or lower
  `bramble_entanglement_per_second` if crossers accumulate too much.
- Briar Trap yield is tuned against the default Bloom radius. A build stacking
  Expansion sows a wider field from the same harvest, since radius feeds both the
  harvested area and the scatter; `briar_trap_power_per_trap` is the dial if that
  turns out to be too generous.
- Siege Thorns scales from the number of enemies standing in the hedge as a
  whole rather than the specific section under attack. A per-section version
  would need an attacker-pressure layer in the field.
- The GDD unlocks Root by maintaining a large amount of Mature territory. The
  prototype has no meta progression, so Root is simply available from the start;
  the unlock condition belongs with the meta layer when it exists.
- Swarm and Parasite remain unimplemented, so nine of the GDD's fifteen Plant
  pairings still have no evolution.
- Development's new erosion resistance applies to Grazer erosion only. Corruptor
  conversion is still slowed by Bramble's base frontier resistance alone, which
  may or may not be the intended asymmetry.

## Presentation and development switches

- The prototype now launches in fullscreen. `display/window/size/mode` is set to
  borderless fullscreen rather than exclusive, so alt-tabbing stays quick and the
  1280x720 viewport keeps its existing `canvas_items` stretch.
- Added four inspector switches to the progression node, one per Plant path.
  Turning a path off keeps it out of both path milestones and out of every
  level-up draft, so a playtest can be narrowed to the paths under test without
  editing code.
- A path a run already holds keeps working when its switch is turned off, and the
  universal Thornshot lines are always draftable, so a run with every path
  switched off still levels up normally instead of stalling on an empty offer.
- A milestone whose whole offer is switched off simply never fires rather than
  presenting an empty choice panel.

## Starting layout: a besieged foothold

- Shrank the starting Green island and wrapped hostile ground around it, so a run
  opens on a foothold under siege instead of on a quarter of the arena facing one
  open frontier. Green begins at 4.95% of the arena rather than 30.7%.
- Moved the fixture's shape out of hardcoded constants and into the tuning
  resource: starting centre, radius, and the hostile mass it faces are authored
  values, and `starting_hostile_ring` sets how deep the encircling hostile band is
  in multiples of the island's own radius. Zero restores an unencircled start.
- Measured the new opening with no player input at all: Green settles from 4.95%
  to 4.05% over twenty seconds and holds, so the foothold trades ground at its
  border rather than collapsing on its own.
- The prototype smoke suite now pins the development path switches on and reads
  the authored reroll allowance instead of assuming three, so tuning those values
  in the Inspector no longer fails unrelated checks.
- The unclaimable-edge check grows Green out to the upper basalt island first
  rather than relying on the starting island touching rock, and the frontier
  erosion comparison re-derives its sample from the pristine fixture.

## Carried forward from the new opening

- With no player input the hostile mass now takes most of the neutral arena within
  twenty seconds, where the old wide start let Green win that race passively. That
  is the intended pressure, but it means the opening minute leans on Seeds and
  Blooms much harder than before and wants playtesting.

## Bramble reframed as crowd control

- Removed the Thorn Damage upgrade line. Thorn damage is now a fixed, modest chip
  effect that nothing scales: a small flat amount plus a fraction of the target's
  maximum health, still ramped by Entanglement but never by investment.
- Bramble's four lines are now Entanglement (maximum slow), Ensnare Rate
  (Entanglement build speed), Grasping Roots (new), and Repulsion (replacing the
  damaging Retaliation). A smoke check pins the shape: maxing all four leaves a
  thorn tick's damage exactly where it started.
- Added Grasping Roots. An enemy that reaches full Entanglement is rooted where it
  stands and cannot move at all until the hold expires, with roots bursting
  visibly beneath it. Selecting Bramble grants a short base hold and the line
  lengthens it. Each rooted enemy is then immune for a spell, so a permanently
  Entangled enemy is held repeatedly rather than held forever, and a root outlives
  the ground that caused it so an enemy shoved off the Green still serves it out.
- Replaced damaging Retaliation with Repulsion. An enemy that damages Green is
  shoved down the territory gradient toward the nearest way out, on the same
  per-enemy cooldown. The shove is stepped rather than teleported so it can never
  push anything through basalt, and Mature ground pushes harder through the Root
  Network. Repulsion interrupts a Grazer instead of handing the player a second
  passive damage source.
- Retuned chip damage against the small starting island. Flat damage moved from
  0.6 to 0.18, the maximum-health fraction from 0.0018 to 0.0005, and the
  fully-Entangled multiplier from 5.5 to 3.0.
- Measured a straight crossing of the starting Green with only the Bramble layer
  resolving. Uninvested: Hunter leaves with 91% health, Grazer 91%, Burrower 98%.
  With Entanglement, Ensnare Rate and Grasping Roots maxed the crossing takes
  longer, so it costs more without ever approaching a kill: Hunter 87%, Grazer
  80%, Burrower 96%. An enemy that instead camps in Green for ten seconds is down
  to 52%, 67% and 95% respectively, so base Bramble wears campers down over about
  twenty seconds rather than killing anything outright.
- Moved the Evolutions' damage off the deleted line. Briar Trap damage is authored
  on the evolution and amplified by the maturity of the ground harvested (base
  raised 34 to 46), and Old Growth eruptions likewise (26 to 34). Bramble's
  Evolutions are now the only place its control turns into real damage.
- Dropped the scene's overrides for the two deleted properties and left every
  other authored Bramble value alone.

## Repulsion becomes a visible shove

- Repulsion now travels over time instead of displacing the enemy in one frame.
  The shove opens at twice its average speed and eases linearly to a stop across
  an authored window, so the distance still lands exactly where it did while the
  motion reads as a knockback rather than a teleport.
- A repelled enemy is staggered for the length of the slide: it does not chase,
  act on territory, or land contact damage until it lands. It still advances in
  small steps that stop dead against basalt, so nothing is ever pushed through a
  wall or off the field.
- Widened what counts as damaging Green. Repulsion previously answered erosion,
  conversion, and hostile spread; it now also answers Warden maturity suppression,
  a Colony Core planted inside the territory, and a Saboteur cutting down a
  catalyst standing on it. The single rule is that anything weakening Green
  provokes it, while the pulse itself still requires the attacker to be standing
  on Green.
- Collapsed the scattered per-behaviour repulsion calls into one flag resolved at
  the end of the territory action, so a new enemy behaviour opts in by saying it
  weakened the territory rather than by remembering to call the effect.
- Covered both: the shove launches with zero instant movement, travels partway
  after two frames, deals nothing on the pulse frame itself, and fires once per
  cooldown; and grazing, hostile conversion, and maturity suppression each provoke
  it.

## Rooted enemies read at a glance

- Gave a rooted enemy a visible hold. Roots clamp around its feet and are drawn
  beneath its body so the enemy itself stays readable, and a ring unwinds from a
  full circle to nothing across the hold, which reads as a timer on how much
  longer the enemy is stuck.
- Enemies now record the full length of the hold alongside its remaining time, so
  the indicator can show a fraction rather than guessing at one.

## Old Growth cue

- Wired the authored `oldgrowth.wav` to the Root Network erupting, on the shared
  SFX bus with its own gain.
- Held the cue behind a short retrigger guard and a capped polyphony. A cascade
  can fire several eruptions inside one frame, and without the guard that stacked
  one identical voice per eruption; now it swells once. Covered by a test that
  fires five eruptions in a frame and expects exactly one cue.

## The clock no longer wins the run

- Running out the timeline at 12:00 no longer ends the run on its own. It retires
  the timeline and opens a Final Stand: nothing more spawns, and victory waits
  until the last hostile on the field is cleared.
- The HUD replaces its countdown with CLEAR THE FIELD and names the era FINAL
  STAND, so the survivor count already in the run label becomes the objective. A
  status line announces the transition once.
- Every defeat condition still applies during the Final Stand, so a run can still
  be lost after the clock is spent, and a level-up taken on the killing blow holds
  the run open until the draft is chosen rather than being skipped.
- Covered by test: a hostile left standing as the clock expires keeps the run
  running and relabels the HUD, and clearing the field then produces victory.

## Suite versus authored values, again

- `flowering_season_bloom_count` is now authored as 1 in the scene, and the smoke
  check still assumed a flowering opens more than one Bloom. It now reads the
  authored count and asserts the stored charge is spent on the flowering the run
  actually authors. This is the third check to collide with an Inspector value;
  the pattern to follow is that a test asserts the rule and reads the number.

## New-changes spec: build structure, Thornshot, Evolution upgrades

Implemented from `docs/new_changes.md`. Sections needing paths that do not exist
yet are listed under carried-forward work below.

### Evolution frees a path slot (sections 5-7)

- Claiming the pair Evolution now consolidates the two paths into one slot and
  frees a third. An evolved run is offered a support path from the two it did not
  consume; the paths that made the Evolution can never be chosen again.
- The support path uses its normal lines, upgrades, and relics, and never forms a
  second Evolution. A claimed pairing is frozen, so choosing a support path can no
  longer re-roll which Evolution the run holds.
- Fixed a latent consequence of the old rule while doing it: `choose_path` cleared
  `active_evolution` on every path choice, which would have wiped the claimed
  Evolution the moment a support path was taken.
- Evolving widens the upgrade slots from six to eight rather than replacing the
  lines already taken, so the support path can actually be developed.
- Taking a support-path line from a draft commits that path, exactly as the first
  two slots already worked.

### 12-minute pacing (section 21)

## Kudzu

Implements sections 9 to 12 of `docs/new_changes.md`. Kudzu is the fifth Plant
path and the first that colonises ground away from the ecosystem.

- Added the path, its four authored lines (Crown Capacity, Rooting Speed, Runner
  Growth, Invasion Strength), and a development switch beside the other four.
- Added `KudzuDirector`, which owns Crowns, kill clustering, runners, and
  colony collapse, and draws all of it in arena space.
- Kills far from owned territory accumulate into clusters rather than planting a
  Crown outright: several kills in roughly the same area are required, the cluster
  drifts toward the newest kill so a moving fight drags the foothold with it, and
  a stale cluster disperses. Kills inside the ecosystem never contribute.
- A new Crown roots before it establishes and is markedly more fragile while it
  does. Establishing opens a small Green foothold; after that the Crown sends
  runners outward on a fixed spiral, so a colony grows evenly and a replayed run
  grows the same shape.
- Runners crawl quickly through neutral ground and much more slowly into hostile
  ground, where Invasion Strength governs both the mass that survives and the
  conversion applied. Runners are drawn as vines crawling to their target.
- Crown capacity caps remote takeover at two by default, rising to five with
  investment, and is enforced against both new clusters and spacing between
  Crowns.
- Hostile control beneath a Crown wears its health down, and a destroyed Crown
  starts its colony receding - but only if that colony is still its own connected
  region. Territory that has already joined the main ecosystem survives, which is
  the lifecycle the spec describes: establish, defend, spread, connect, stabilise.
- Added the two field queries this needed: connected-region lookup and a cheap
  "is there owned territory within this radius" test.
- Added the four Kudzu pairings by name so a Kudzu run recognises its Evolution.
  Their mechanics are not implemented yet, and they correctly resolve to no
  Evolution upgrade line rather than a broken one.
- Dropped the scene's override for `seed_bank_interval_seconds`, which the
  Germination Season rework had already removed from the script.

## Kudzu Evolutions

Implements section 13. All four act through the Crown network rather than adding
a separate mechanic beside it.

- Sporulation: established Crowns periodically throw a Seed at the enemies nearest
  their colony, and a Seed germinating on remote ground becomes a Crown itself, so
  one outbreak breeds the next. A Crown near the arena edge retries around the
  circle rather than throwing its Seed off the field and wasting the interval.
- Wildflower Network: every Crown becomes a Bloom origin and the network fires as
  a relay. The first Crown Blooms on the frame the network wakes and the rest
  follow one relay step apart, so the sequence reads as a chain crossing the arena
  rather than one simultaneous flash.
- Briar Bastions: a Crown that is losing health erupts in its own defence,
  damaging, Entangling, and rooting whatever is standing on the colony. Each Crown
  holds its own cooldown, so several colonies answer independently.
- Rhizome Network: connected colonies repair their Crowns and feed maturity back
  into their ground between synchronized surges. A surge pushes every connected
  colony outward at once using pressure alone and injects no new Plant mass, so
  Seeds stay the only real source of new territory.
- Added the supporting API these needed: a public root-eruption entry point and a
  nearest-enemy query on combat, plus `queue_maturity_support` on the field.
- Clamped the maturity stamp to 0-to-1 in both directions while adding that
  support path; it previously had no upper bound, so a negative suppression could
  have pushed maturity past full.
- Added launch, relay, and surge counters to the Kudzu director, which the tests
  assert against and which are worth having in the HUD later.

## Growth-line slot tray

- Replaced the upgrade tray's run-on text summary with a row of rounded square
  slots, one per growth line the run can hold: six open from the start and two
  drawn locked until the Evolution frees them.
- Each slot shows an abbreviation taken from the line's authored name and its
  level, so the row reads at a glance and no second set of names has to be kept
  in sync.
- Hovering a slot gives what the line is, what the next rank buys, and what the
  run's numbers resolve to right now: damage per Thornshot, seconds between
  volleys, kills per Seed, seconds to full Entanglement, root and immunity
  windows, knockback distance, Crown capacity and rooting time, and so on. The
  resolved figures are read from the same values the systems use, so the hover
  text cannot drift from what the run is actually doing.
- An Evolution line's hover reads out the rank the run has actually reached,
  since each of its ranks does something different.
- Empty and locked slots explain themselves too, the locked pair naming what
  claiming the Evolution will do.
- Added slot ordering to progression: a line keeps the slot it first took for the
  rest of the run. The order is rebuilt from the levels rather than recorded on
  selection, so debug and test mutation land in slots the same way play does.
- `UpgradeSlots` owns only presentation and builds its own children, so the
  scene carries one node rather than sixteen, and the slot count, size, spacing,
  and palette are all authored on it.
