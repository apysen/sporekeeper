# Changelog: 2026-08-31

## Pause overlay legibility, a main menu exit, and the Clover machine leaving Campaign

This entry covers work completed after `2026-08-30.md`. It records the final
behavior of each change rather than the intermediate passes.

---

## 1. The pause dim no longer falls on the HUD

Pausing used to grey the whole screen, including the two surfaces a player pauses in
order to read: the right-side HUD and the bottom relics tray. The dim is meant to take
the battlefield out of the way, not the readouts.

- `SidePanel` and `UpgradeTray` now draw at `z_index = 21`, above the pause overlay's
  `20`, so the dim passes underneath them.
- The overlay's own children — the dev-controls card, the pause panel, and the settings
  page — carry `z_index = 2`, which is relative and so resolves to `22`. They stay above
  the raised HUD.
- Nothing was repositioned. The pause panel is centered and the raised surfaces sit
  against the right and bottom edges, so no control changed which pixels it occupies.

---

## 2. The pause menu can leave a run

- Added **MAIN MENU** between **GLOSSARY** and **QUIT TO DESKTOP**. The pause panel grew
  58px to hold it; every other row kept its authored position.
- `_return_to_main_menu()` closes the menu and defers a scene change to the home screen.
  The run is abandoned rather than saved — the home screen starts a fresh one.
- The home screen path is a string constant rather than a `preload`. The home screen
  preloads the run scene, and preloading both directions is a cycle.

---

## 3. Campaign runs without the Clover machine

The run already asks for enough attention without a side game to gamble on. Campaign
drops the machine entirely; **Quick keeps all of it, unchanged**.

Both modes share one run scene, so this is a mode gate read once in `_ready` rather than
a deletion. When Campaign is selected:

- The cabinet is hidden, which takes the reels, the lever, the stake meter, and the odds
  line with it. The all-in countdown is hidden with it.
- The **ADAPTATIONS** rows move up into the space the cabinet held. Their destination is
  read off the cabinet's own position rather than hardcoded, so the two stay in step if
  the scene moves either one.
- Nothing behind the machine is advanced: the machine itself, the wager preview, the
  jackpot windows, all-in grace, the lever, and the reels are all skipped per frame.
- The lever, the wager notch, the hover preview, and the two wager/odds debug reports are
  gated, so no ground can be staked by any route.

Nothing else in the run depended on it. No relic touches the machine — Clover was left
without a relic pool on purpose — and the field glossary carries no Clover entries.
